# Formulario de montaje schema-driven

- La FUENTE DE VERDAD del contrato con el backend es
  `Backend_GCodeMaster/docs/contrato_utillajes_frontend.md`.
- No dupliques ese contrato en el frontend ni lo escribas a mano: el formulario
  de montaje es schema-driven (se pinta desde la API `/utillajes`), así que una
  familia nueva del backend aparece sola.
- No hardcodees campos por familia.
