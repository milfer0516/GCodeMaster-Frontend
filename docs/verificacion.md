# Verificación proporcional

| Tipo de cambio | Verificación |
|---|---|
| Visual o de texto | Compilar y reportar. Sin scripts de medición. |
| Lógica | Probar el comportamiento afectado. |
| G-code, geometría o parámetros de corte | Verificación exhaustiva contra archivos/datos reales, comparación antes/después, y prueba de que la salida no cambió salvo lo esperado. |
